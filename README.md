# The Raeburn Group Engineering

Source for the public engineering site at **https://engineering.theraeburngroup.com**.

This repository is the organisation GitHub Pages repository for **The Raeburn Group**.

## Purpose

The site provides a restrained public engineering and open-source presence for the Group, separate from the main corporate website and from individual product repositories.

## Publication

GitHub Pages should publish from the `main` branch root.

The custom domain is declared as:

`engineering.theraeburngroup.com`

DNS and GitHub Pages custom-domain verification must also be configured before the custom domain becomes active.

## Positioning

The site is intentionally Group-first. Public repositories currently represent selected engineering work and should not be interpreted as the balance of the Group's commercial activities.
